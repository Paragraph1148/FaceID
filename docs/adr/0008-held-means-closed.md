# A held Class Session is a closed one, counted per Student

The synopsis divides Attendance Credit by the number of "held" Class Sessions without defining held, and F5.5 only rules out cancelled ones. Reports count a Class Session as held once it is **closed**. While it is open its unmarked Students still have absent records, so counting it would show a class in progress as absences that may never happen. For each Student, held means the closed Class Sessions they have an Attendance Record for, i.e. the ones they were Expected at when the session opened.

## Considered Options

- **Held = not cancelled (open and closed)**: the literal reading, but a report run during class shows everyone not yet marked as absent.
- **Held = every closed session of the Subject**: a Student registered mid-semester would be charged for classes held before they existed in the system.

## Consequences

- A Class Session nobody closes never counts. The Faculty's Class Sessions list shows it as open, and a session from an earlier day can only be closed (ADR 0007), so it's visible, not silent.
- Two Students in the same Subject can have different Held counts, which the reports show in their own column.
- Reports say which sessions they count, in a note under each title.
